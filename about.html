Applying IT111 Concepts

1. History of Computing

An important development in computing was the move from large early computers toward smaller and more powerful computers. This development helped make computing technology more accessible and useful in everyday life.

2. Computer Systems: Input → Processing → Storage → Output

When I create this portfolio, I use input devices such as a keyboard to enter code. The computer processes the code, stores the files on the computer, and the browser produces the website as the output that I can see on the screen.

3. Connected World

When someone visits a website, their device connects to a network and uses the Internet to communicate with a server. A browser requests the web page and displays the information that the server sends back.
